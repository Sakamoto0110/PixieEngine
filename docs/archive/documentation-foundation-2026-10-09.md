The owner asked for a documentation structure before any code, reusing the
rigor of the documentation contracts from the agent workplace tooling and
NekoLib, while warning that those contracts were still being validated and
were not to be taken as fully correct.

The structure was derived from NekoLib's documentation schema version 1 and
adapted: root `ROADMAP.md`, `TODO.md`, and its child `TASKLIST.md`;
`docs/archive/` in place of `docs/history/`; the unversioned `.local/`; and a
lighter module model. PIXIE-TODO-001 was promoted for this work, and the result
was the initial commit. The entry closed later, in PIXIE-ARCHIVE-008.
